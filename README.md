# EKS Monitoring Setup (Prometheus + Grafana)

## 📌 Overview
This folder contains the setup for monitoring our EKS cluster using Prometheus and Grafana.

### ✅ What’s included:
- Creating EKS cluster using `eksctl`
- Migrating nodes from `t2.micro` → `t3.small` safely
- Installing Prometheus + Grafana via Helm
- Accessing Prometheus (9090) and Grafana (3000)

### 🔧 Tools Used:
AWS EKS • eksctl • Kubernetes • Helm • Prometheus • Grafana
